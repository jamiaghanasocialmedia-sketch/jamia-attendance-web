# Jamia Attendance - web version (iPad / any browser)

Same Firebase project, logins and data as the Android app. Open the published address in Safari on the iPad,
sign in, then Share > Add to Home Screen. Published with GitHub Pages from the public repo jamia-attendance-web (copy of this folder).
If sign-in complains about the API key, register a Web app in Firebase console > Project settings and paste its
`firebaseConfig` into `firebase-config.js`.
